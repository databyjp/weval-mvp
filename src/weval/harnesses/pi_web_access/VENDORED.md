# Pinned pi-web-access runtime

`pi.py` installs the `pi-web-access` Pi extension from these files. It copies
the lockfile, `web-search.json`, and `provenance.json` into each Trial's agent
logs.

- `package-lock.json` is generated by npm. Do not hand-edit it.
- `package.json` and `provenance.json` pin the release. To change the version,
  update both together, then regenerate the lockfile with npm.
- `web-search.json` is the extension's search and fetch config.
